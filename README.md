# Cotizador TransAndina Carga S.A.S.

Aplicación web en Streamlit para estimar tarifas de carga usando integración
numérica (Simpson y trapecio), cálculo diferencial y optimización.

## Ejecutar en local
```bash
python -m venv venv
venv\Scripts\activate        # Windows
pip install -r requirements.txt
streamlit run app.py
```

## Ejecutar en la web
Desplegada con Streamlit Community Cloud (archivo principal: `app.py`).
